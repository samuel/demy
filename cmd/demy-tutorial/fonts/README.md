# Bundled bitmap fonts

These BDF pixel fonts are embedded into the tutorial binary to demonstrate
demy's bitmap-font rendering. They are vendored verbatim from upstream.

## Spleen 8x16 — `spleen-8x16.bdf`

- Author: Frederic Cambus — https://www.cambus.net/ / https://github.com/fcambus/spleen
- License: BSD 2-Clause (see `SPLEEN-LICENSE`)

## Tom Thumb / Fixed4x6 — `tom-thumb.bdf`

- Author: Robey Pointer — https://robey.lag.net/2010/01/23/tiny-monospace-font.html
- License: MIT (see `TOMTHUMB-LICENSE`)

A tiny 4x6 proportional font, used here to exercise demy's per-glyph advance
(proportional) bitmap layout.
